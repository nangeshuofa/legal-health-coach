# 量化评估工具（v2.0 新增，v2.1 增强）

本模块为「数据说话」原则提供可落地的计算与评分工具。评估时优先调用本文件中的公式与量表，避免凭感觉下结论。所有数值标准均标注依据，便于向用户解释"为什么"。

---

## 一、身体指标计算

### 1. BMI（身体质量指数）

**公式**：`BMI = 体重(kg) ÷ 身高(m)²`

**中国成人分级标准**（依据《中国成人超重和肥胖症预防控制指南》）：

| BMI 范围 | 分级 | 法律人提示 |
|---------|------|-----------|
| < 18.5 | 偏瘦 | 注意营养与体力 |
| 18.5 – 23.9 | 正常 | 维持，防反弹 |
| 24.0 – 27.9 | 超重 | 法律人高发，启动体重管理 |
| ≥ 28.0 | 肥胖 | 代谢风险显著，建议就医评估 |

> 法律人注意：BMI 正常不代表安全。长期久坐、肌肉量低的人可能「隐性肥胖」，需结合腰围判断。

### 2. 腰围（中心性肥胖核心指标）

**测量方法**：站立、放松，软尺绕肚脐上 1 cm 水平一周，正常呼气末读数。

**中国标准**：
- 男性 ≥ 90 cm、女性 ≥ 85 cm → 中心性肥胖（腹型肥胖）
- 此为代谢综合征诊断标准之一

### 3. 腰臀比（WHR）

**公式**：`WHR = 腰围(cm) ÷ 臀围(cm)`

**判断标准**：
- 男性 > 0.9、女性 > 0.85 → 腹型肥胖，心血管与代谢风险升高

### 4. 标准体重速算

**公式（简易）**：`标准体重(kg) ≈ 身高(cm) − 105`

- 实际体重在 ±10% 内为正常
- ±10%–20% 为超重 / 偏瘦，> 20% 为肥胖 / 消瘦

## 二、代谢综合征自测评分

**诊断标准**（依据中华医学会糖尿病学分会（CDS）《中国 2 型糖尿病防治指南（2020 版）》，具备以下 3 项及以上即可诊断）：

> **v2.1 口径说明**：CDS 2020 版腰围切点为男 ≥ 90 / 女 ≥ 85 cm、空腹血糖切点 6.1 mmol/L；IDF 国际标准切点不同（腰围种族特异、空腹血糖 5.6 mmol/L）。本技能统一采用 CDS 2020 版口径；解读体检报告时注意机构可能采用 IDF / WHO 口径，不要直接混比。

| 项目 | 阳性标准 |
|------|---------|
| ① 腹型肥胖 | 腰围 男≥90cm / 女≥85cm |
| ② 高血糖 | 空腹血糖 ≥ 6.1 mmol/L，或已确诊糖尿病 |
| ③ 高血压 | 血压 ≥ 130/85 mmHg，或已确诊高血压 |
| ④ 高甘油三酯 | TG ≥ 1.7 mmol/L |
| ⑤ 低高密度脂蛋白 | 男 < 1.04 / 女 < 1.3 mmol/L |

**评分输出**：

```
满足项数：__ / 5
诊断结论：
  • 0-1 项 → 🟢 低风险，保持现状
  • 2 项   → 🟡 临界，启动生活方式干预
  • ≥3 项   → 🔴 代谢综合征，建议就医 + 系统管理
```

**法律人高发原因**：久坐 + 应酬 + 压力 + 不规律饮食，四项几乎全员命中，务必每年监测。

## 三、睡眠质量评分（简化 PSQI）

> 改编自《匹兹堡睡眠质量指数（PSQI）》，保留 7 个核心维度，每题 0–3 分，总分 0–21。仅供自评参考。
>
> **v2.1 划界说明（v2.2 口径统一）**：原版 PSQI 按成分权重计分，常用界值为总分 > 7 提示睡眠质量差；本简化版改为 7 维度等权加总，分数分布与原版不可直接换算，下表划界为本技能经验性设定。统一解读口径：0–5 分良好；6–7 分轻度下降（常规观察）；8–10 分需关注（启动调整）；> 10 分或困扰持续 > 2 周按睡眠障碍对待，建议就医。不要把本简化分与医院或专业量表的 PSQI 结果直接对比。

| 维度 | 问题 | 评分 |
|------|------|------|
| 入睡时间 | 上床到睡着通常多久？0=≤15分 1=16–30分 2=31–60分 3=>60分 | |
| 睡眠时长 | 平均每晚睡几小时？0=≥7h 1=6–7h 2=5–6h 3=<5h | |
| 睡眠效率 | 实际睡眠/卧床时间？0=≥85% 1=75–84% 2=65–74% 3=<65% | |
| 夜间觉醒 | 每晚醒几次？0=0次 1=1次 2=2–3次 3=≥4次 | |
| 安眠药物 | 近一月用助眠药频率？0=无 1=偶尔 2=有时 3=经常 | |
| 日间功能 | 白天疲惫/瞌睡影响工作？0=无 1=轻微 2=明显 3=严重 | |
| 睡眠质量 | 主观睡眠质量？0=很好 1=较好 2=较差 3=很差 | |

**结果分级**：

```
总分：__ / 21
  • 0–5 分  → 🟢 睡眠良好
  • 6–10 分 → 🟡 睡眠质量下降，需调整
  • >10 分  → 🔴 睡眠障碍，建议就医（尤其持续 >2 周）
```

## 四、压力水平评分（简化 PSS）

> 改编自《知觉压力量表（PSS-10）》，评估近一月感受，每题 0–4 分，总分 0–40。

**10 题（0=从不，1=偶尔，2=有时，3=常常，4=总是）**：

1. 因突发事情感到心烦意乱
2. 感觉无法掌控生活重要事项
3. 感到紧张焦虑、压力大
4. 能有效应对棘手问题（反向计分：4→0, 3→1, 2→2, 1→3, 0→4）
5. 感到凡事尽在掌握（反向计分）
6. 因事情超出掌控而生气
7. 困难堆积太多，无法克服
8. 能从容应对（反向计分）
9. 因琐事而烦躁
10. 感到困难大到难以承受

**结果分级**（沿用 PSS-10 原版划界）：

```
总分：__ / 40
  • 0–13 分 → 🟢 低压力
  • 14–26 分 → 🟡 中等压力，主动减压
  • 27–40 分 → 🔴 高压力，建议专业帮助（咨询/精卫）
```

> 法律人提示：庭审季、结案期分数常短暂升高属正常；若长期 >26 分并伴睡眠/情绪问题，参考 `皮质醇管理.md` 并考虑 EAP/心理咨询。

## 六、法律人健康总分模型（示例）

将以上维度归一化加权，得到「健康总分（百分制）」示例口径，用于趋势追踪：

```
健康总分 = 代谢(30%) + 体重体型(15%) + 睡眠(15%) + 压力(15%) + 职业防护(15%) + 运动(10%)

等级：
  • 85–100 → 优秀
  • 70–84  → 良好
  • 60–69  → 及格（重点关注短板维度）
  • < 60    → 需系统干预
```

> 说明：该模型为**自我管理用的粗略加权示例**，非临床诊断工具，权重为经验设定、无临床循证依据，不代表医学风险排序。使用边界：
> - 总分与等级**仅限同一用户、同一口径下做纵向趋势对比**，不得用于人群比较，不得作为疾病风险或疗效结论
> - 维度归一化方法不唯一，须在报告中注明本次采用的归一化口径；口径变更后历史分数不可直接续用
> - 向用户输出总分时必须附带一行声明："健康总分为自我管理参考分，非临床评分，不代表医学诊断"
> - 短板维度优先改善，详见对应模块

## 使用要点

1. 计算前先确认用户数据完整，缺失项标注「待确认」而非估算。
2. **单位防错（v2.2 新增）**：接收血糖 / 血压 / 血脂数值时，若明显偏离合理范围（如空腹血糖 > 30 mmol/L 或 < 1 mmol/L、收缩压 > 260 或 < 60 mmHg），先确认单位与数值来源再计算，禁止直接套公式——血糖存在 mmol/L（国内通用）与 mg/dL（部分进口仪器报告）两套单位，换算关系 ≈ ÷18。
2. 评分结果配合 `报告模板.md` 的风险评估栏目输出。
3. 同一用户多次测量时做**趋势对比**，比单次绝对值更有意义。
4. 任何量表仅作筛查，阳性结果提示「该关注 / 该就医」，不等于确诊。
5. 向用户解读分数时，同步说明量表为简化改编版及其划界局限（见各量表"划界说明"），避免用户将结果与临床测评混用。
