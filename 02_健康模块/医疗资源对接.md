# 医疗资源轻量对接

> **v2.0 增强**：新增耳鼻咽喉科（嗓音）、眼科（视屏）就诊指南，呼应[护眼与嗓音养护](护眼与嗓音养护.md)模块。

## 模块定位

本模块提供**轻量级**医疗资源对接服务，不做医生推荐、不做挂号服务，聚焦于：
- 就诊提醒、就诊资料整理、复诊清单生成、医疗信息管理

> 年度体检项目规划见 [年度体检清单](../../03_参考资料/年度体检清单.md)；日常护眼护嗓预防见 [护眼与嗓音养护](护眼与嗓音养护.md)。

## 法律人高频科室补充（接新模块）

### 耳鼻咽喉科（嗓音 / 咽喉）
**看什么**：持续声嘶 > 2 周、咽干异物感、用声疲劳、声带不适
**就诊准备**：
- 记录声嘶时长、与用声的关系、是否伴咽痛 / 咳血
- 避免过度清嗓习惯说明
- 必要时做喉镜（无创，门诊即可）
**紧急信号**：声嘶伴呼吸困难、咳血 → 立即就医

### 眼科（视屏 / 干眼）
**看什么**：持续眼干、视疲劳、视力下降、眼痛、飞蚊突然增多
**就诊准备**：
- 记录每日看屏时长、症状出现场景
- 停用含血管收缩剂眼药水，带现用人工泪液信息
- 干眼可做泪液分泌 / 泪膜检查
**紧急信号**：视力骤降、眼痛伴头痛、突发大量飞蚊+闪光 → 立即就医

## 就诊准备清单

### 就诊前准备

**1. 资料准备**
- 身份证/医保卡
- 既往病历（纸质或电子版）
- 检查报告（按时间顺序整理）
- 用药清单（药名、剂量、用法）
- 过敏史记录
- 本次不适的时间线记录

**2. 问题清单**
提前写好要问医生的问题，避免就诊时忘记：
- 我这个病是什么原因引起的？
- 需要做什么检查？
- 检查结果什么时候能拿到？
- 治疗方案有几种选择？
- 这个药要吃多久？有什么副作用？
- 下次什么时候复诊？
- 生活上需要注意什么？

**3. 身体准备**
- 空腹检查（如抽血、腹部B超）：前一天晚上10点后不进食
- 需要憋尿的检查（如泌尿系B超）：提前喝水
- 穿容易穿脱的衣服
- 不要化妆（影响医生观察面色）

---

### 就诊中注意事项

**1. 准确描述病情**
- 哪里不舒服？
- 从什么时候开始的？
- 持续了多久？
- 什么情况下会加重/减轻？
- 有没有其他伴随症状？
- 之前看过吗？做过什么检查？吃过什么药？

**2. 认真听医生说**
- 不懂就问，不要不懂装懂
- 重要的记下来（或录音，需征得医生同意）
- 检查报告出来后及时找医生看

**3. 检查注意事项**
- 问清楚每项检查的注意事项
- 问清楚什么时候出结果
- 问清楚结果出来后怎么找医生

---

### 就诊后整理

**1. 资料归档**
- 病历、检查报告、处方拍照存档
- 按时间+医院+科室命名
- 建立个人健康档案

**2. 用药管理**
- 记录药名、剂量、用法
- 设置服药提醒
- 注意药物相互作用
- 不要自行停药或加减量

**3. 复诊提醒**
- 记录下次复诊时间
- 提前预约挂号
- 准备好复诊需要带的资料

## 常见检查项目说明

### 常规体检项目

| 检查项目 | 查什么 | 注意事项 |
|---------|-------|---------|
| 血常规 | 感染、贫血、血液系统问题 | 无需空腹 |
| 尿常规 | 泌尿系统、肾脏问题 | 留中段尿 |
| 肝功能 | 肝脏功能 | 需空腹 |
| 肾功能 | 肾脏功能 | 需空腹 |
| 血脂 | 胆固醇、甘油三酯 | 需空腹，前3天清淡饮食 |
| 血糖 | 糖尿病筛查 | 需空腹8-12小时 |
| 心电图 | 心脏电活动 | 无需空腹，安静后做 |
| 胸片/CT | 肺部问题 | 孕妇不做 |
| 腹部B超 | 肝、胆、胰、脾、肾 | 需空腹 |
| 甲状腺B超 | 甲状腺 | 无需空腹 |

### 专科检查

**消化科**
- 胃镜：需空腹，检查前6-8小时不进食
- 肠镜：需要提前清肠
- 幽门螺杆菌检测：空腹或餐后2小时

**心内科**
- 动态心电图：24小时，正常活动
- 心脏彩超：无需特殊准备
- 运动平板：穿运动鞋

**内分泌科**
- 糖化血红蛋白：无需空腹
- 糖耐量试验：需空腹，喝糖水后多次抽血
- 甲状腺功能：无需空腹

## 不同科室就诊指南

### 内科（全科/普内）
**看什么**：发热、咳嗽、腹痛、头晕等不确定哪个科的问题
**就诊时机**：
- 普通不适先看全科
- 全科医生会分诊

### 心内科
**看什么**：胸闷、胸痛、心慌、高血压、心律失常
**紧急信号**：
- 胸痛伴大汗、呼吸困难 → 立即120
- 持续胸痛超过15分钟 → 立即就医

### 消化内科
**看什么**：胃痛、腹胀、腹泻、便秘、肝病
**就诊准备**：
- 记录症状与饮食的关系
- 带上之前的检查报告

### 呼吸科
**看什么**：咳嗽、气喘、胸闷、肺炎
**就诊准备**：
- 记录咳嗽的时间、性质
- 有没有痰，痰的颜色

### 内分泌科
**看什么**：糖尿病、甲状腺疾病、肥胖
**就诊准备**：
- 记录血糖/血压监测数据
- 用药清单

### 神经内科
**看什么**：头痛、头晕、失眠、手脚麻木
**就诊准备**：
- 记录头痛/头晕的特点
- 什么时候发作、持续多久

### 骨科
**看什么**：颈肩腰腿痛、骨折、关节炎
**就诊准备**：
- 疼痛部位、性质、持续时间
- 之前的影像资料

### 皮肤科
**看什么**：皮疹、瘙痒、皮肤问题
**就诊准备**：
- 不要涂抹药膏（影响医生观察）
- 拍照记录变化

## 法律人就医时间管理

### 预约挂号技巧

1. **提前预约**：专家号提前1-2周约
2. **利用APP**：医院官方APP、微信公众号
3. **捡漏技巧**：
   - 就诊前1-2天可能有人退号
   - 当天早上可能放号
4. **备选方案**：
   - 挂不到专家号先挂普通号
   - 先做检查，再找专家看结果

### 节省时间技巧

1. **初诊**：
   - 先挂普通号开检查
   - 检查结果出来后再挂专家号

2. **复诊**：
   - 提前预约
   - 准备好所有资料
   - 列好问题清单

3. **检查安排**：
   - 需要空腹的检查安排在上午
   - 同一天可以安排多项检查
   - 提前问清楚每项检查的时间

### 年度体检规划

**建议时间**：每年固定时间，如生日前后

**必查项目**：
- 基础套餐：血尿常规、肝肾功能、血脂血糖、心电图、胸片、腹部B超
- 法律人加项：甲状腺B超、颈椎腰椎、眼底检查、心理测评
- 40岁以上加项：肿瘤标志物、胸部CT、胃肠镜（根据情况）

**体检后**：
- 认真看体检报告
- 异常项及时复查
- 建立健康档案，每年对比

## 健康档案管理

### 应该保存的资料

1. **基础信息**
   - 血型、过敏史
   - 既往病史
   - 手术史
   - 家族病史

2. **体检报告**
   - 每年体检报告
   - 按时间顺序保存
   - 标注异常项及变化

3. **就诊记录**
   - 门诊病历
   - 住院记录
   - 检查报告
   - 处方记录

4. **用药记录**
   - 正在用的药
   - 用过的药及效果
   - 药物过敏记录

### 整理建议

- 按时间+医院+科室分类
- 重要报告拍照存手机
- 纸质资料用文件夹整理
- 每年整理一次

## 紧急情况处理

### 需要立即就医的情况

**心血管急症**
- 胸痛持续超过15分钟
- 胸痛伴大汗、呼吸困难、恶心
- 突然心慌、头晕、眼前发黑
→ 立即拨打120，不要自己开车去

**脑血管急症（中风）FAST原则**
- Face：脸歪了
- Arm：一侧手抬不起来
- Speech：说话不清楚
- Time：立即打120
→ 越快越好，黄金3小时

**其他急症**
- 严重外伤、大出血
- 昏迷、意识不清
- 呼吸困难
- 剧烈腹痛
- 严重过敏反应
→ 立即120

### 急救包常备

- 创可贴、碘伏、纱布
- 退烧药（布洛芬/对乙酰氨基酚）
- 胃药（奥美拉唑/达喜）
- 止泻药（蒙脱石散）
- 抗过敏药（氯雷他定）
- 体温计、血压计
- 个人常用药

## 注意事项

1. **本模块仅提供健康管理建议，不替代专业医疗诊断**

3. **遵医嘱用药，不要自行加减药**
4. **定期体检，早发现早治疗**
5. **紧急情况拨打120，不要耽误**
