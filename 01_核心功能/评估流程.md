# 健康评估流程（v2.2）

本文档描述法律人健康管理教练的完整评估流程，供使用者自我评估或 AI 助手执行评估时参考。v2.0 强化了**引导式提问**、**量化评分接入**与**本地数据追踪**；v2.1 补充了档案数据结构标准与无文件系统时的降级路径；v2.2 新增确诊人群分流、同生态技能让位与追踪触发接入。

## 评估总览

采用「**四层递进**」模式：

```
第一层：身份与场景判断 → 第二层：引导式采集 → 第三层：量化评估 → 第四层：方案输出
    ↓                      ↓                    ↓                  ↓
  什么人/什么问题        补齐关键信息          打分定位风险        给方案+追踪
```

---

## 第一步：判断身份与场景类型

### 身份确认

先确认用户是否为法律从业相关人群（律师 / 法官 / 检察官 / 法务 / 实习 / 其他）。未自报时 1 句话询问；确认后进入法律人专属逻辑，未确认则给通用建议并提示可定制。

**触发让位（v2.1 新增，v2.2 扩展）**：以下情况不进入本流程——用户明确不是法律从业者且不关心职业场景适配；问题为一次性通用健康知识问答；运行环境中存在用户专属的饮食合规 / 健康管理技能且已建立个人档案时，饮食与数据追踪类咨询优先让位或协作输出。

### 场景判断

| 场景 | 触发关键词 | 典型表述 |
|------|-----------|---------|
| A. 健康评估类 | 体质辨识、自测、全面评估、健康检查 | "帮我做个健康评估""我是什么体质" |
| B. 每日追踪类 | 记录、今日、打卡、血糖、体重、步数 | "今天空腹血糖 6.5""记一下体重" |
| C. 方案生成类 | 方案、计划、处方、帮我制定 | "给我个运动处方""调一下作息" |
| D. 量化自测类 | 算 BMI、测压力、睡眠打几分 | "算算我 BMI""测测压力大不大" |

## 第二步：引导式采集（关键，避免凭空下结论）

**不要一上来输出长篇报告。** 用 3–5 个选择题补齐关键信息，用户已提供的跳过。

### 首次评估提问脚本（可勾选式）

**1. 基础数据**（用于 BMI / 腰臀比 / 代谢风险）
- 年龄：___ 性别：___ 身高：___cm 体重：___kg 腰围：___cm

**2. 职业状态**
- □ 实习律师 □ 执业律师 □ 合伙人 □ 法官 □ 检察官 □ 法务
- 平均每日久坐：□ <6h □ 6–8h □ >8h
- 平均每日看屏：□ <6h □ 6–8h □ >8h
- 平均每日高强度用声：□ <1h □ 1–2h □ >2h

**3. 生活方式**
- 熬夜（12 点后睡）频率：□ 几乎不 □ 偶尔 □ 经常
- 运动频率：□ <2 次/周 □ 2–3 次/周 □ >3 次/周
- 应酬 / 外卖频率：□ 少 □ 一般 □ 多

**4. 当前困扰（多选）**
- □ 失眠 / 睡不好 □ 肩颈腰疼痛 □ 压力大 / 焦虑
- □ 腹胀 / 消化差 □ 视疲劳 / 干眼 □ 嗓子干 / 声嘶
- □ 血糖 / 血压 / 血脂异常 □ 容易累 / 没精神

**5. 已有指标**（如有）
- 近期血糖 ___ / 血压 ___ / 血脂 ___ / 体检异常项 ___

> 采集原则：用选择题降低负担；信息不全的报告里标注「待确认」，绝不估算或臆断。

## 第三步：量化评估（接入工具模块）

**确诊人群分流（v2.2 新增）**：用户已自报确诊 2 型糖尿病 / 高血压 / 血脂异常等慢性病时，跳过对应的筛查评分——筛查对已确诊者没有信息增量——直接进入 `代谢综合征管理.md` 的指标监测与趋势解读，并补充追问：确诊时间、当前控糖 / 控压目标、用药情况（如愿意提供）、近期监测频率。筛查量表仅用于未确诊人群的初筛。

**确诊状态未知时的衔接规则（v2.4.1 新增）**：用户未声明确诊状态时，默认按健康人群口径执行（筛查量表可用）；但涉及 GMI、糖化等糖尿病前期切点解读时，须同步提示"非糖尿病人群 GMI 与实验室 HbA1c 偏差更大，确诊状态以体检静脉血 HbA1c 或医院诊断为准"，并在首次信息采集时确认确诊史，确认后再按分流规则切换口径。

根据采集到的数据，调用 `02_健康模块/量化评估工具.md` 完成评分：

| 已有数据 | 调用工具 | 输出 |
|---------|---------|------|
| 身高 + 体重 | BMI 公式 | BMI 值与分级 |
| 腰围 / 臀围 | 腰围 + 腰臀比 | 中心性肥胖判断 |
| 代谢指标（血糖/血压/血脂/腰围） | 代谢综合征评分 | 0–5 项，诊断结论 |
| 睡眠情况 | 简化 PSQI | 0–21 分，睡眠分级 |
| 压力自述 | 简化 PSS | 0–40 分，压力分级 |
| 久坐/用屏/用声 | 职业劳损评分 | 0–6 分，劳损分级 |

评分结果填入报告「核心风险评估」各维度，形成 🟢/🟡/🔴 分级依据。

## 第五步：结构化输出与数据追踪

### 输出格式

- A 类 → `报告模板.md`「模板一：健康评估报告」（含健康总分雷达）
- B 类 → 「模板二：每日健康日报」+ 趋势对比（读 `daily_log.csv`）
- C 类 → 「模板三：专属方案文档」+ SMART 目标
- D 类 → 「模板四：量化自测结果」

### 本地健康档案（v2.0 新增，v2.1 增强，B 类必做）

当用户首次追踪时询问是否建立本地档案（默认 `健康档案/`）：

```
健康档案/
├── profile.json     # 身份、年龄、身高、体重、腰围、过敏史
├── daily_log.csv    # 每日数值记录（v2.1 起为 CSV，表头见 SKILL.md 第五步）
├── goals.md         # SMART 目标 + 21 天打卡表
└── trend.md         # 周/月趋势对比
```

- `daily_log.csv` 表头：`date,weight_kg,fasting_glucose,bp_systolic,bp_diastolic,sleep_hours,steps,exercise_min,meals_note,symptoms_note,extra`；数值缺失留空，禁止估算补值
- 旧版 `daily_log.md` 存在时，首次追踪提示用户可迁移为 CSV，不同意则沿用旧文件
- 每次追踪先读 `daily_log.csv` 计算较昨日 / 周趋势，再输出日报
- 异常波动按 `代谢综合征管理.md`「趋势预警硬线」（v2.2）判定，触发即主动提醒并建议就医 / 更新目标
- 支持定时任务的环境，按 SKILL.md 第五步「触发接入」商定每日提醒时点；连续 3 天无记录降频提醒，连续 7 天暂停推送并确认意愿
- 用户拒绝建档则仅本次会话轻量追踪，不做跨会话对比
- **环境不支持本地文件读写时（v2.1 新增）**：不做跨会话追踪，明确告知用户局限并建议自行留存数据，禁止假装建档或写入临时位置冒充档案

## 评估原则

### 1. 法律人视角优先
所有建议须结合法律人职业特点（久坐、高压、不规律、高强度脑力、长时间用声用屏），通用建议须做场景适配。

### 2. 分级干预
- 🟢 正常：保持 + 预防
- 🟡 关注：生活方式调整 + 定期监测
- 🔴 预警：明确就医，辅以临时缓解

### 3. 可落地优先
每条建议具体到「什么时候做、做多久、怎么做」，拒绝"多运动""注意休息"空话。

### 4. 数据说话
评估须有依据；量化指标优先用 `量化评估工具.md`；用户数据充分利用，缺失标注「待确认」。

### 5. 循证标注
医学标准、临界值、量表标注来源并尽量写明版本 / 年份，提升可信度，保持通俗；改编类量表须说明简化方式与划界局限（见 `量化评估工具.md`）。

### 6. 不替代医生
本工具提供健康管理建议，不替代专业医疗诊断，治疗遵医嘱。

---

## 边界说明

- 仅覆盖法律人**自身**健康管理，不含家属
- 医疗资源对接为轻量版：就诊提醒、资料整理、复诊清单，不做医生推荐 / 挂号
- 护眼 / 嗓音模块聚焦预防与日常养护，明显症状须就医
- 所有建议基于通用健康知识与法律人职业特点，具体诊疗请遵医嘱
