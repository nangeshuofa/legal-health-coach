# 健康评估流程

本文档描述法律人健康管理教练的完整评估流程，供使用者自我评估或 AI 助手执行评估时参考。

## 评估总览

法律人健康评估采用「**三层递进**」模式：

```
第一层：场景判断 → 第二层：维度评估 → 第三层：方案输出
    ↓                    ↓                    ↓
  什么类型的问题      评估哪些维度         给出什么方案
```

---

## 第一步：判断场景类型

根据用户需求，判断属于以下哪类场景：

### A. 健康评估类（一次性评估+建议）

**触发关键词**：体质辨识、自测、全面评估、健康检查、帮我看看身体、我这个体质怎么办

**典型场景**：
- "帮我做个健康评估"
- "我是什么体质？"
- "最近总感觉累，怎么回事？"
- "失眠怎么办？"

**评估深度**：全面

---

### B. 每日追踪干预类（持续性记录+反馈）

**触发关键词**：记录、今日、打卡、血糖、体重、步数、健康日报

**典型场景**：
- "今天空腹血糖6.5"
- "记录一下，今天体重70公斤"
- "帮我看看这周的健康数据"
- "今天吃什么比较健康"

**评估深度**：轻量，聚焦当日数据

---

### C. 方案生成类（定制化方案）

**触发关键词**：方案、计划、处方、帮我制定、给我一个

**典型场景**：
- "给我一个运动处方"
- "帮我制定一个饮食方案"
- "我想调整作息，有什么建议？"
- "压力大怎么办，给个方案"

**评估深度**：聚焦单一维度，深度定制

## 第三步：结构化评估输出

### A. 健康评估类输出格式

```
【法律人健康评估报告】

一、基础画像
  职业阶段：[实习/执业/合伙人/法官/检察官]
  核心风险标签：[如：久坐高危、代谢预警、压力过载等]

二、体质辨识结果
  主导体质：[如：脾虚湿盛型]
  兼夹体质：[如：气滞血瘀]
  典型表现：[2-3条与用户情况匹配的典型症状]

三、核心风险评估
  🟢 正常 / 🟡 关注 / 🔴 预警
  • 代谢维度：[评估+依据]
  • 骨骼肌肉维度：[评估+依据]
  • 心理健康维度：[评估+依据]
  • 睡眠质量维度：[评估+依据]

四、改善建议（按优先级排序）
  🔥 紧急干预（1-2周内见效）：
    1. [具体建议]
    2. [具体建议]
  
  📌 中期调整（1-3个月）：
    1. [具体建议]
    2. [具体建议]
  
  🌱 长期养护（持续坚持）：
    1. [具体建议]
    2. [具体建议]

五、法律人专属提醒
  [针对法律职业特点的1-2条特别提醒，如开庭日应急方案、加班日能量补给等]
```

---

### B. 每日追踪类输出格式

```
【今日健康日报】📅 [日期]

一、数据概览
  • 空腹血糖：X.X mmol/L [↑/↓/→ 较昨日]
  • 体重：XX.X kg [↑/↓/→ 较昨日]
  • 血压：XXX/XX mmHg [如提供]
  • 步数：XXXX 步
  • 睡眠：X.X小时 [质量描述]

二、今日状态评估
  整体状态：🟢良好 / 🟡一般 / 🔴需关注
  关键解读：[1-2句话总结今日数据背后的含义]

三、今日建议
  • 饮食：[1条具体建议]
  • 运动：[1条具体建议]
  • 节律：[1条具体建议]

四、明日预告
  [如果明天有特殊安排（如开庭/出差），给出针对性健康预案]
```

---

### C. 方案生成类输出格式

```
【法律人专属方案：[方案名称]】

适用场景：[什么情况下用这个方案]
预期效果：[坚持后能达到什么效果]
执行难度：⭐⭐⭐（5星制，越难星越多）

一、核心原则
  [3条最核心的原则，用"为什么+怎么做"表述]

二、具体方案
  【方案细节，分模块列出，每条要具体可执行，不要空话】
  例：
  • 晨起5分钟：[具体动作]
  • 开庭间隙：[具体动作]
  • 晚间放松：[具体动作]

三、法律人场景适配
  [针对开庭、加班、出差、伏案等典型法律人场景的适配方案]

四、注意事项
  • [禁忌/风险提示]
  • [如何判断是否有效]
  • [出现什么情况需要就医]
```

## 评估原则

### 1. 法律人视角优先
所有建议必须考虑法律人的职业特点——久坐、高压、不规律、需要高强度脑力输出。通用健康建议必须经过"法律人场景适配"才能输出。

### 2. 分级干预
根据问题严重程度给出不同等级的建议：
- 🟢 正常：保持现状 + 预防性建议
- 🟡 关注：生活方式调整 + 定期监测
- 🔴 预警：明确建议就医，辅以临时缓解方案

### 3. 可落地优先
每条建议都要具体到"什么时候做、做多久、怎么做"，避免"多运动"、"注意休息"这类空话。

### 4. 数据说话
涉及评估时，必须有依据，不能凭空下结论。用户提供的数据要充分利用，没有数据的地方明确标注"待确认"。

### 5. 不替代医生
明确声明本工具提供健康管理建议，不能替代专业医疗诊断。涉及具体疾病治疗，建议遵医嘱。

---

## 边界说明

- 本工具仅覆盖法律人**自身**的健康管理，不包含家属健康管理
- 医疗资源对接为**轻量版**：提供就诊提醒、资料整理、复诊清单，不做医生推荐、不做挂号服务
- 所有建议基于通用健康知识和法律人职业特点，具体诊疗请遵医嘱
