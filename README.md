# 法律人健康管理教练

> 法律人专属数字健康教练——基于律师、法官、检察官的职业特点（久坐、高压、不规律饮食、睡眠不足、长时间用声用屏），提供「健康评估 + 建议」与「每日追踪 + 干预」双轨服务。

**当前版本：v2.3.0** · 开源协议：GPL-3.0 · 作者：楠哥说法（黄楠律师）

---

## 这个项目解决什么

法律人的健康痛点很特殊，通用健康百科答不到点上：

- **懂你**：连续高强度开庭、赶 deadline 熬夜、饭局应酬连轴转
- **懂你的身体**：久坐的颈腰椎、压力导致的皮质醇紊乱、不规律饮食的代谢问题、长期用声用屏的咽喉与视力损耗
- **懂你的节奏**：高压周期和低谷期的不同策略

| 维度 | v1.0 | v2.0 |

| 交互方式 | 直接输出报告 | 新增**引导式分步提问**，先补齐关键信息再给建议 |
| 每日追踪 | 无持久化 | 新增**本地健康档案 + 趋势追踪 + 21 天打卡**机制 |
| 模块导航 | 各自独立 | 全模块**交叉引用 + 场景速查表**，评估后可直接跳转 |
| 循证性 | 部分标准 | 关键数值 / 量表**标注依据来源** |

## v2.3 升级要点（相对 v2.2）

- **血糖管理术语与指标手册**（新参考资料）：CGM 十项核心指标及国际共识目标分层、TIR 与 HbA1c 换算、血糖波动五项中国成人参考值（MAGE / LAGE / MODD / SDBG / PPGE）、GMI 计算公式、AGP 报告五步解读法
- **防误读设计**：标注厂商 APP 分级口径与国际共识差异（如 1 级高血糖下限 10.1 vs 7.8 mmol/L），解读前先核对报告定义；CV 受均值下移影响的解读陷阱说明
- **口径统一**：代谢综合征管理模块与每日追踪日报的血糖数值解读统一引用手册口径

## v2.2 升级要点（相对 v2.1）

- **追踪触发接入**：支持定时任务的环境可商定每日固定时点提醒（建议 21:00–21:30），连续 3 天无记录降频、7 天暂停确认——补上"有记录无触发"的闭环断点
- **确诊人群分流**：已确诊糖尿病 / 高血压 / 血脂异常者跳过筛查评分，直接进入指标监测与趋势解读
- **趋势预警硬线**：血糖连续 3 天 > 7.0、收缩压连续 3 天 ≥ 140、体重一周波动 > 2 kg、静息心率一周上升 > 10 次/分，触发即主动提醒
- **触发让位扩展**：运行环境存在用户专属饮食合规 / 健康管理技能时优先让位或协作
- **隐私声明如实化**：按运行环境如实表述存储位置（本地 / 云端），开启追踪前告知用户
- **口径修正**：简化 PSQI 四段解读口径统一；新增血糖 / 血压数值单位防错规则

## v2.1 升级要点（相对 v2.0）

- **循证补强**：简化 PSQI / PSS 补充原版界值、简化方式与划界局限说明；代谢综合征标准标注 CDS 2020 版口径及与 IDF 的差异
- **总分解释边界**：健康总分模型加注"自我管理参考、非临床评分"，限定仅作纵向趋势对比
- **档案结构升级**：`daily_log.md` → `daily_log.csv` 结构化存储（含标准表头），支持长期趋势计算与旧文件迁移
- **降级路径**：运行环境不支持本地文件读写时，明确降级为会话内轻量追踪，不伪造档案
- **触发让位规则**：非法律从业者或纯通用健康问答不再抢答，交还通用能力
- **细节修正**：CHANGELOG 年份勘误、量化工具编辑残留清理、README 模式数量更正

## 服务模式（四种）

| 模式 | 适用场景 | 输出 |
|------|---------|------|
| **健康评估** | 全面评估、体质辨识、专项咨询 | 健康评估报告（含健康总分雷达） |
| **每日追踪** | 持续记录数据、日常健康管理 | 每日健康日报（含趋势对比） |
| **方案生成** | 定制运动 / 饮食 / 作息 / 护嗓方案 | 专属方案文档（SMART 目标） |
| **量化自测** | 算 BMI、测压力、睡眠打几分 | 量化自测结果 |

## 快速开始

**① 健康评估**（引导式）
> 用户：「帮我做个健康评估」
> 教练：先问 3-5 个关键问题（职业、身高体重腰围、当前困扰）→ 调量化工具算分 → 出评估报告

**② 量化自测**（工具型）
> 用户：「算算我 BMI，身高 175 体重 85」
> 教练：BMI=27.8 → 超重 → 中心性肥胖风险 → 建议测腰围 + 看饮食模块

**③ 每日追踪**
> 用户：「今天空腹血糖 6.5，体重 78，睡了 6 小时」
> 教练：读历史档案 → 算趋势 → 出今日日报 + 明日开庭预案

**④ 方案生成**
> 用户：「给我个护嗓方案，我最近开庭多嗓子哑」
> 教练：调护眼与嗓音模块 → 出科学用声方案 + 开庭日适配

## 常见问题

**Q：这和普通健康 App 有什么区别？**
A：所有建议都经过"法律人场景适配"——开庭日、加班日、应酬日、出差日各有方案，不是通用模板。

**Q：我的健康数据安全吗？**
A：健康档案只写入你授权的档案目录，不用于其他用途。存储位置随运行环境而定——本地环境存于本地，云端环境存于云端工作目录，开启追踪前会告知实际位置，请自行评估隐私边界。拒绝建档则仅本次会话轻量追踪；运行环境不支持文件读写时，会明确告知并降级为会话内追踪，不伪造档案。

**Q：能替代医生吗？**
A：不能。本工具是健康管理建议，不替代诊断治疗。红色预警与急症信号会明确提示就医。

**Q：中医部分能当治疗用吗？**
A：穴位、茶饮、泡脚是日常养护，不是治疗。明显症状请就医。
