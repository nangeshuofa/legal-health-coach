# 法律人健康管理教练

> 法律人专属数字健康教练——基于律师、法官、检察官的职业特点（久坐、高压、不规律饮食、睡眠不足、精神高度紧张），提供「健康评估+建议」与「每日追踪+干预」双轨服务。

## 项目简介

本项目是专为法律职业人群打造的健康管理技能，不是通用健康百科，而是懂法律职业痛点的贴身教练：

- **懂你**：知道连续开庭12小时是什么体验
- **懂你的身体**：久坐带来的颈椎腰椎问题、压力导致的皮质醇紊乱、不规律饮食引发的代谢问题
- **懂你的节奏**：高压周期和低谷期的不同健康策略

## 核心特点

### 精准定位
- 聚焦法律职业人群的健康痛点
- 5种法律人常见体质辨识（脾虚湿盛/肝郁气滞/心脾两虚/湿热内蕴/肝肾阴虚）
- 开庭日、加班日、应酬日、出差日等场景化方案

### 三大服务模式

| 模式 | 适用场景 | 输出形式 |
|------|---------|---------|
| **健康评估** | 一次性全面评估、体质辨识、专项咨询 | 健康评估报告 |
| **每日追踪** | 持续记录健康数据、日常健康管理 | 每日健康日报 |
| **方案生成** | 定制运动/饮食/作息方案 | 专属方案文档 |

### 八大健康模块

1. **体质辨识** - 5种法律人常见体质自测与调理
2. **代谢综合征管理** - 血糖/血压/血脂三大指标管理
3. **饮食调理方案** - 分场景饮食指南与红黑榜
4. **运动处方库** - 5大运动处方，从碎片到系统
5. **皮质醇管理** - 30个减压技巧，压力管理
6. **起居节律管理** - 睡眠优化与生物钟调节
7. **中医自助保健** - 穴位/舌诊/泡脚/代茶饮
8. **医疗资源对接** - 就诊准备与健康档案管理

## 使用方法

### 作为 Coze Skill 使用
1. 在扣子（Coze）平台安装本技能
2. 直接对话即可触发健康评估或咨询
3. 支持自然语言交互，无需复杂操作

### 作为开源项目使用
- 直接浏览 `02_健康模块/` 下的各模块文档
- 参考 `01_核心功能/评估流程.md` 进行自我评估
- 使用 `01_核心功能/报告模板.md` 记录健康状况

## 免责声明

**免责声明**：本工具提供的健康管理建议仅供参考，不构成医疗诊断或治疗方案。具体健康问题请咨询专业医生。如需获得更多支持，可与黄楠律师联系，联系方式微信：huangnan2010

**紧急情况红线**：以下情况立即就医，不要使用自助方案：
- 胸痛、胸闷、呼吸困难
- 血压持续≥180/110mmHg
- 血糖持续＞16.7mmol/L或＜3.9mmol/L
- 严重失眠超过2周伴情绪问题
- 剧烈头痛伴呕吐
- 任何"非常难受"、"受不了"的情况
